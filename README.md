# AI 投资参考平台

面向投资小白的投资信息解释与研究方向发现 Demo。它把热点行业、代表公司、基础投资术语和风险因素用更容易理解的方式组织起来，帮助用户找到值得继续研究的方向。

> 本项目内容仅用于产品演示、投资学习和信息参考，不构成任何证券、基金、期货或其他金融产品的投资建议。投资有风险，决策需谨慎。

## Demo 范围

- 热点行业观察：用演示数据展示市场可能关注的行业方向、关注逻辑和风险点。
- 行业详情解读：用小白能理解的语言解释行业、产业链、代表公司类型和关键指标。
- 行业 / 公司查询：支持输入演示关键词，返回结构化解释和研究线索。
- 投资术语速查：解释 K 线、日线、估值、市盈率等常见概念。
- 风险提示：关键模块均标注“仅供参考，不构成投资建议”。
